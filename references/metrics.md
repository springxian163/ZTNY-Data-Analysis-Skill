# 指标定义与计算口径

本文档说明 `analyzer.py` 里每个指标的准确定义。改动分析逻辑前请先读这里，
否则容易在报告里出现两套互相矛盾的数字。

---

## 0. 通用约定

| 符号 | 含义 |
|------|------|
| `year_cur` | 最新一年（数据中最晚年份） |
| `year_prev` | 基期年（最新年份 - 1） |
| `months` | 可比月份列表，如 `[1..9]` |
| `cmp` | 只在 `months` 内、且年份属于这两年的记录子集 |
| `cur` / `prev` | `cmp` 按年份切分的两份 |
| 金额单位 | 元（含税验收金额） |

**所有指标都只在 `cmp` 上计算**，不使用全量数据。这是保证同比可比的前提。

---

## 1. 可比区间（`meta`）

```python
determine_compare_months(df) -> (year_cur, year_prev, months, note)
```

算法：
1. 取 `year_cur` 的 `业务日期.max()`，得到截止月 `M`；
2. 计算该月金额占本年比重，若 `< 2%` 且 `M > 1`，说明该月只有零星数据，`M -= 1`；
3. `months = range(1, min(M, 基期实际最大月) + 1)`。

> 为什么要设 2% 阈值：实践中最后一期导出常只包含当月 1—2 天的数据。
> 若直接纳入，会让该年总额虚高一点，但更严重的是单月同比会失真（如 -95%），
> 干扰月度波动的判断。

---

## 2. 总量（`totals`）

| 字段 | 公式 |
|------|------|
| `amount_cur` / `amount_prev` | `cur.验收金额.sum()` / `prev.验收金额.sum()` |
| `amount_yoy` | `(amount_cur - amount_prev) / amount_prev × 100` |
| `amount_delta` | `amount_cur - amount_prev`（元） |
| `orders_cur` / `orders_prev` | 行数 |
| `avg_order_cur` | `amount_cur / orders_cur` |
| `avg_order_yoy` | 平均单笔金额的同比 |
| `suppliers_cur` | `cur.供应商名称.nunique()` |
| `materials_cur` | `cur.物料编码.nunique()` |
| `annual_forecast` | `amount_cur / len(months) × 12` |

**读法**：`orders_yoy` 与 `avg_order_yoy` 的方向组合是判断采购形态的关键。
笔数大涨 + 单笔大降 = 采购碎片化；笔数降 + 单笔升 = 采购集中化。

---

## 3. 月度（`monthly`）

按 `月序` 透视 `验收金额`，逐个可比月份给出 `prev` / `cur` / `yoy`。

`monthly_summary.volatile`：当 `max(yoy) - min(yoy) > 100pp` 时为 True，
提示月间波动过大，采购节奏缺乏计划性。

---

## 4. 物资类别（`categories`）

按 `物资类别` 透视，给出每类的 `prev` / `cur` / `yoy` / `share`。

`share` 的分母是 `cur` 的总金额，不是全量。

### 消耗性 vs 资本性分组（`rules._split_categories`）

| 组 | 成员 | 解读方向 |
|----|------|---------|
| 消耗性 | 材料、备件 | 反映生产维护强度 |
| 资本性 | 移动设备、固定设备、大型部件 | 反映投资节奏 |

消耗性涨 + 资本性跌 → 存量设备维护压力上升，需与检修计划交叉验证。
这是最容易误读的一组关系，不要简单说成"采购在缩减"。

---

## 5. 供应商集中度（`supplier_concentration` / `top_suppliers` / `supplier_churn`）

按年把供应商按金额降序排列，`CRn = 前 n 家金额之和 / 总金额 × 100`。

| 指标 | 含义 | 健康区间（经验） |
|------|------|-----------------|
| CR1 | 最大供应商占比 | < 15% 较安全 |
| CR5 | 前五家占比 | 25%—40% 较合理 |
| CR10 | 前十家占比 | < 50% |
| CR20 | 前二十家占比 | — |

**CR5 下降不必然是好消息**。下降可能来自：①主动引入竞争（好）；
②采购碎片化导致单笔金额变小（中性）；③原有主力供应商供货能力下降（坏）。
必须结合 `supplier_churn` 和 `big_orders` 一起看。

`supplier_churn`：`both` 两年都合作、`new` 今年新增、`lost` 今年流失，
另附 `new_amount` / `lost_amount`（金额）、`new_median` / `lost_median`（单家中位数）、
`lost_idle_median`（退出供应商停供天数中位数）。

### 新增 / 退出供应商名单（`supplier_new` / `supplier_lost`）

```python
新增 = 基期可比区间无验收记录  AND  本期可比区间有记录
退出 = 基期可比区间有记录      AND  本期可比区间无记录
```

每家给出：`amount` 金额、`share` 占比、`orders` 笔数、`materials` 物料种数、
`avg_order` 平均单笔、`top_cat` 主营类别及其占比、`first_date` / `last_date`。
退出名单额外给出 `idle_days` = **本期数据截止日 − 最后验收日期**（停供天数）。

- 用「数据截止日」而非「今天」做基准，保证同一份数据反复运行结果完全一致。
- **退出 ≠ 终止合作**。长周期设备、专项工程类供应商可能因本期无需求而自然缺席，
  这份名单是核查线索，不是结论。

### 细分品类集中度（`category_concentration`）

对材料/备件/移动设备/固定设备逐类算 CR3 与 TOP1 占比。
整体 CR5 下降但某品类 TOP1 > 30% 时，说明分散是"表面分散"。

---

## 6. 大额订单（`big_orders`）

`验收金额 > 1,000,000` 的记录。给出笔数、总额、占本年金额比重、按供应商汇总 TOP8。

用途：判断大额支出是否集中在少数装备制造商，这些是单点议价的关键对象。

---

## 7. 逾期（`overdue` / `overdue_distribution` / `overdue_suppliers`）

### 清洗
`逾期天数` 为 NaN 或 `< -3000` 的记录排除在逾期分析之外（不排除在金额分析外）。

### 两个层面必须分开看

| 层面 | 指标 | 含义 |
|------|------|------|
| 逾期面 | `rate` = 逾期笔数 / 有效笔数 | 有多少比例的订单逾期 |
| 逾期深度 | `avg_days` = 逾期订单的平均逾期天数 | 逾期了多久 |
| 严重程度 | `severe_share` = 逾期 > 60 天的占比 | 有多少是长期拖欠 |

**典型陷阱**：逾期率两年持平（15.0% → 15.2%）但 `avg_days` 从 24.3 涨到 37.6。
如果只看逾期率会得出"交付稳定"的错误结论。真实情况是逾期正从偶发变为常态。

### 分布区间（`overdue_distribution`）
`未逾期 / 1-7天 / 8-15天 / 16-30天 / 31-60天 / 60天以上`，按年给占比。

### 逾期供应商（`overdue_suppliers`）
本年逾期记录的供应商聚合：逾期笔数、平均逾期天数、涉及金额，按笔数降序 TOP10。

`avg_days > 60` 的供应商要单独质疑**合同条款真实性**，而不是质疑履约能力——
工业气体这类当日配送的品类不可能真的平均逾期 100 天。

---

## 8. 验收效率（`accept_efficiency`）

`间隔 = 业务日期 - 验收申请日期`（天）。

给出本年/基期平均间隔、本年最大值。

间隔变长意味着验收环节积压，会推迟结算，间接影响供应商后续供货意愿。

---

## 9. 价格（`price`）

### 可比物料筛选
```python
两年均有采购  AND  各自年度采购数量 ≥ 10
```
单价 = 该物料该年的 `验收金额.sum() / 验收数量.sum()`（加权均价，不是简单平均）。

| 字段 | 含义 |
|------|------|
| `comparable` | 可比物料种数 |
| `mean_change` / `median_change` | 涨幅的平均/中位 |
| `down_share` | 单价下降的物料占比 |
| `up20_count` | 涨幅 > 20% 的物料数 |
| `up20_amount` | 这些物料本年采购金额 |
| `down_count` | 单价同比下降的物料种数 |
| `down5_count` | 降幅 ≥ 5% 的物料种数（"显著下降"口径） |
| `down5_amount` | 上述物料本期采购金额 |
| `max_drop` | 单种最大降幅（负数） |
| `top_up` | 涨幅 > 20% 中按金额排序的 TOP25 |
| `top_down` | 降幅 ≥ 5% 中按金额排序的 TOP25 |

**降价榜为什么要设 5% 门槛**：单价同比 -0.1% 属于正常议价波动，
若按"所有下降"排序，榜单会被柴油、锚杆这类超大金额、微幅波动的品种占满，
看不到真正值得复盘的降价案例。设 5% 门槛后，榜单才有可比性。

**为什么用中位数判断整体水平**：涨幅分布长尾严重（少数物料涨 200%+），
平均数会被拉偏。中位数才是"典型物料"的变化。

---

## 10. 同规格价差（`price_gaps`）

```python
按 (物料描述, 供应商名称) 聚合均价
筛选：每供应商采购数量 ≥ 20
筛选：该物料描述下供应商 ≥ 2 家
筛选：max(均价) / min(均价) ≥ 1.5
按涉及金额降序取 TOP8
```

**局限**：只识别"同码不同价"，识别不了"同物异码"（同一物资录成多个描述）。
后者需要物料主数据治理，不在本分析的覆盖范围内。

---

## 11. 使用单位（`units` / `blank_unit`）

按 `使用单位` 透视，给出 `prev` / `cur` / `yoy` / `share`，降序 TOP15。
空值统一显示为「（未填/设备直供）」。

`blank_unit.share` 的分母是**可比区间金额**，与 `quality_report` 里全量口径的
`金额占比%` 不同。报告同时给出两个口径，避免读者对不上账。

---

## 12. 长尾与小额（`tail`）

| 字段 | 定义 |
|------|------|
| `small_count_cur` | 金额 < 1,000 元的订单数 |
| `small_share_cur` | 占本年笔数比 |
| `small_amount_share` | 占本年金额比 |
| `once_material` | 本年只被采购 1 次的物料编码数 |
| `once_share` | 占本年物料总数比 |

小额订单占比 > 40% 且金额占比 < 5% → 典型的流程成本负担。
`once_share` > 50% → 物料编码膨胀严重。

---

## 13. 协议类型（`agreement`）

按 `协议类型` 透视两年金额，用于判断框架协议覆盖率是否提升。

---

## 14. 关键词异动（`hot_keywords`）

取 `物料描述` 前 4 个字符作为粗粒度品类，聚合两年金额，
筛选 `笔数 ≥ 20 且本年金额 ≥ 500 万`，找出 `yoy > 50%` 的品类 TOP5。

**这是粗筛**，只用于发现"哪个方向在异常放量"，不作为精确品类归集。
真正的品类分析要做物料主数据分类。
